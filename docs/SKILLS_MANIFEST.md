## Installation and security notes

- Skills were copied from the exact pinned Git revisions into Claude Code's documented project skill directory. Their upstream license files are preserved as `UPSTREAM_LICENSE` in each skill folder.
- The official Taste `install.sh` defaults to symlinking into `~/.claude/skills`; it was inspected but not run. The UI UX Pro Max npm CLI installs globally by default and was not installed. Impeccable's `npx` setup was not run.
- No skill installer or skill script was executed during the file-copy step. See [AI_AGENT_VERIFICATION.md](AI_AGENT_VERIFICATION.md) for actual discovery/invocation results.
- A skill can contain executable code and network behavior. Review source changes when updating revisions. Keep app dependencies separate from developer skills.
- The architecture-diagram-generator, C4 diagramming, and diagram-design skills are installed project-locally under `.agents/skills/`. Their source trees and pinned revisions are recorded above; optional export/rendering tools are not installed as application dependencies.
