# Reports

Reports provide deterministic period-based summaries, cash flow, category and
tag spending, budget performance, goal progress, and net-worth trends. CSV
export and custom date ranges are available in the frontend. Monetary API
values use integer minor-unit strings; percentages are derived presentation
metrics.
