# Design and frontend status

## Current state

The design and milestone reports in this folder record how the frontend was planned and built. They are historical evidence, not the live specification for current behavior. The current implementation includes the HTTP data source, category management, Quick Add envelope suggestions, and Kakeibo views; see the [frontend README](../../frontend/README.md) and [beginner learning guide](../LEARNING_GUIDE.md).

The repository now includes Playwright browser tests and automated Axe checks, but this does not mean a manual screen-reader or physical-device review occurred. Historical reports retain their original test scope and limitations. Current production deployment is unverified for the latest source; see [ROADMAP current status](../architecture/ROADMAP.md#current-source-and-release-status).
