# Budgeting

Budget allocations are maintained per reporting period and category. Cleared
expense transactions in the period determine actual spend.

## Forecasting

The Budget page shows a deterministic period-end projection for each active
allocation. It annualizes cleared expense spend by elapsed calendar days in
the active reporting period and compares the projected amount with the
allocation.

This is a pace indicator, not a complete cash-flow forecast. It does not yet
include future recurring obligations, paydays, or planned goal contributions.
AI-generated insights must not replace these totals.
